# F62 扫码创建与邀请增量

基线 ea5bf9d。只补扫码，不重做已验收的独立详情/范围多选。

原版依据：`deva/apps/desktop/src/main/services/remote/feishu-onboard.ts:50` 调用 registerApp（createOnly、preset、addons）；`remote/index.ts:140` 将扫码用户加入白名单，`:225` 开始扫码、`:281` 取消；`remote/hub.ts:165-224` 邀请是 6 位 /pair 码、10 分钟、5 次错误作废，原版没有第二套飞书邀请二维码。Telegram 创建仍需 BotFather Token，其认领 URL 现在也渲染真实 QR。
