# 本应用（Deva 重写）的运行依赖，与 app/pyproject.toml 的 [project.dependencies] 保持一致。
# 入库模板 app/pyproject.toml.example 的 dependencies 必须保持为空（克隆者不继承维护者的 pin，
# 该约束由 app/tests/test_build_tool_compat.py 强制）；这里记录本应用实际需要的最小集合。
# 安装：pip install -r app/requirements.txt
# QML 界面使用 Essentials；飞书连接、浏览器配对及手机 relay 使用 Addons 的 QtWebSockets。
# 发行构建按实际 import 裁剪 Addons，QtWebEngine 不进入发行包。
PySide6-Essentials==6.11.2
PySide6-Addons==6.11.2
pydantic==2.14.3
# 模型请求的 HTTP 客户端：http_client.py 直接 import httpx，SSE 解析与
# 连接复用都建在它的 API 上；漏声明会让打包产物在装配时 ModuleNotFoundError。
httpx==0.28.1
# 密钥存储：cryptography 提供 AES-256-GCM / HKDF，见 app/src/mvvm/services/secrets_crypto.py。
# 不自实现的原因：GCM 的计数器、认证标签与侧信道防护不能靠 hashlib/hmac 拼出来，
# 自己写等于把密钥安全押在未经验证的代码上；cryptography 的 wheel 内置 OpenSSL，无需系统头文件。
cryptography==46.0.3
# 系统钥匙串：keyring 对接 GNOME Keyring / KWallet / macOS Keychain / Windows 凭据管理器。
# 不自实现的原因：每个平台的钥匙串协议都不同（D-Bus Secret Service、Security.framework、
# Win32 CredRead/CredWrite），自己写等于重新实现一遍跨平台凭据管理。
# 后端不可用时（本容器解析到 keyring.backends.fail）自动退到加密文件，见 secrets_vault.py。
keyring==25.7.0
# Python 3.8 没有 typing.Annotated：app/src/mvvm/models/chat_models.py 按
# sys.version_info 显式分支，3.8 走 typing_extensions。
# 4.13.2 是最后一个支持 3.8 的版本（4.14.0 起 Requires-Python >=3.9），不能随手升级。
# 必须带环境标记：pydantic 2.14.3 要求 typing-extensions>=4.16.0，把 4.13.2 钉死在
# 3.9+ 上会让解析直接冲突。3.9+ 由 pydantic 自己拉取满足其下限的版本。
typing_extensions==4.13.2; python_version < "3.9"
